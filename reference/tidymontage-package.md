# tidymontage: Tidy Microscopy Montages for Scientific Papers

The goal of 'tidymontage' is to streamline the creation of
publication-ready microscopy figure montages. Images are described in a
tidy data frame, and montage components such as projections, exposure,
colours, colormaps, merges, crops, zooms and scale bars are added with a
consistent, pipeable syntax. Pixels are read lazily, and montages are
drawn and saved at an exact physical size.
